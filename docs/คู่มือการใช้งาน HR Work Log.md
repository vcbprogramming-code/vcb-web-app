# คู่มือการใช้งาน — ระบบบันทึกการปฏิบัติงานประจำวันหน้างาน (HR Work Log)

เอกสารฉบับนี้จัดทำขึ้นสำหรับผู้ใช้งานของ **บริษัท วิจิตรภัณฑ์ก่อสร้าง จำกัด**
ครอบคลุมทั้งการใช้งานประจำวัน การตั้งค่าระบบ และหัวข้อสำหรับการอบรม
อ้างอิงตามเกณฑ์การตรวจรับงาน Module 2

---

## 1. ใครทำอะไรได้บ้าง

ระบบแบ่งสิทธิ์เป็น 5 ระดับ ผู้ดูแลระบบกำหนดให้แต่ละคนได้เองจากหน้าจอ
โดยไม่ต้องแก้ไขโปรแกรม

| บทบาท | ทำอะไรได้ | ทำอะไรไม่ได้ |
|---|---|---|
| **ผู้บันทึกข้อมูลหน้างาน** | บันทึกงานรายวันของโครงการที่รับผิดชอบ ยื่นคำขอลาแทนพนักงาน | ยืนยันข้อมูล · เห็นโครงการอื่น |
| **ผู้ตรวจสอบโครงการ** | ตรวจและยืนยันข้อมูล อนุมัติการลา | บันทึกข้อมูลรายวัน |
| **เจ้าหน้าที่ HR** | บันทึกและดูข้อมูลตามโครงการที่รับผิดชอบ | ยืนยันข้อมูล (เว้นแต่ได้รับสิทธิ์เพิ่ม) |
| **ผู้บริหาร** | ดูได้ทุกโครงการ ยืนยันข้อมูล อนุมัติการลา | แก้ไขข้อมูลที่หน้างานบันทึก |
| **ผู้ดูแลระบบ** | ทุกอย่าง รวมถึงปลดล็อกย้อนหลังและปิด/เปิดงวด | — |

> **กฎที่ระบบบังคับเสมอ** ผู้ที่บันทึกข้อมูลจะยืนยันข้อมูลของตัวเองไม่ได้
> และผู้ที่ยื่นคำขอลาจะอนุมัติคำขอนั้นเองไม่ได้

---

## 2. งานประจำวันของผู้บันทึกหน้างาน

1. เปิดเมนู **บันทึกงานฝ่ายบุคคล** แล้วเลือกไซต์งานที่มุมขวาบน
2. ไปที่แท็บ **แรงงาน-วัน** แล้วเลือกวันที่ปฏิบัติงาน
3. กรอกช่อง **แรงงาน-วัน** (สูงสุด 1 ต่อคนต่อวัน — ระบบคิดชั่วโมงให้เอง 8 ชั่วโมง = 1)
4. เลือก **สถานะการทำงาน**: ปกติ / ล่วงเวลา / Standby / ลา / ขาดงาน

### บันทึกทั้งทีมพร้อมกัน
ถ้าคนทั้งทีมทำงานเหมือนกัน ให้ติ๊กเลือกรายชื่อ (หรือกด **เลือกทั้งหมด**)
ตั้งค่าแรงงาน-วันและสถานะที่แถบด้านบน แล้วกด **บันทึกให้ทุกคนที่เลือก**
ระบบยังแยกเก็บเป็นรายคน จึงตรวจสอบย้อนหลังรายบุคคลได้เหมือนเดิม

### เมื่อสัญญาณอินเทอร์เน็ตหลุด
ถ้าหน้างานไม่มีสัญญาณ ระบบจะขึ้นแถบสีเหลืองว่า *ขณะนี้ออฟไลน์*
ข้อมูลที่กรอกไว้จะถูกเก็บไว้ในเครื่องและ **ส่งให้อัตโนมัติเมื่อกลับมาออนไลน์**
โดยไม่บันทึกซ้ำ ไม่ต้องกรอกใหม่

### แนบรูปหรือเอกสารประกอบ
กดที่คอลัมน์ **ไฟล์ประกอบ** ของแถวนั้นเพื่อแนบรูปหน้างานหรือเอกสาร
ไฟล์เปิดดูและดาวน์โหลดได้ตลอดเวลา

---

## 3. การตรวจสอบและยืนยัน (ผู้ตรวจสอบโครงการ)

1. เปิดแท็บ **แรงงาน-วัน** เลือกวันที่ต้องการตรวจ
2. ตรวจตัวเลขในตาราง
3. กด **ยืนยันข้อมูลของวันนี้**

เมื่อยืนยันแล้ว ระบบบันทึกชื่อผู้ยืนยันและเวลาไว้ และข้อมูลวันนั้นจะแก้ไขไม่ได้
จนกว่าจะกด **ยกเลิกการยืนยัน**

สถานะของข้อมูลแสดงอยู่ 3 ระดับ

| ป้าย | ความหมาย |
|---|---|
| **แก้ไขได้** | ยังอยู่ในระยะเวลาที่แก้ไขได้ |
| **ใกล้ครบกำหนด** | เหลือเวลาอีกไม่นานจะล็อกอัตโนมัติ |
| **ล็อกแล้ว / ปิดงวดแล้ว** | แก้ไขไม่ได้ ต้องให้ผู้ดูแลระบบปลดล็อกพร้อมเหตุผล |

---

## 4. การขอลาและอนุมัติ

1. แท็บ **การลา** → **ขอลาใหม่**
2. เลือกพนักงาน ประเภทการลา และช่วงวันที่
3. เลือก **ลาเต็มวัน / ครึ่งวันเช้า / ครึ่งวันบ่าย** (ครึ่งวันนับเป็น 0.5 วัน)
4. แนบใบรับรองแพทย์ได้ถ้ามี

ระบบจะเตือนถ้าวันที่ขอลาชนกับวันที่บันทึกงานไว้แล้ว และจะไม่ให้ยื่นคำขอซ้อนช่วงเดิม
เมื่ออนุมัติแล้ว วันลาจะถูกเขียนลงตารางงานอัตโนมัติ ไม่นับเป็นแรงงาน-วันที่ผลิต

---

## 5. รายงาน

แท็บ **รายงานและตรวจสอบ** เลือกช่วงวันที่แล้วดูได้ 4 มุมมอง:
รายโครงการ · รายทีม · รายประเภทงาน · รายพนักงาน

- **รายงานนี้เป็น PDF** — สำหรับพิมพ์เข้าที่ประชุม
- **รายงานเดือนนี้ ทุกโครงการ (Excel)** — ทุกโครงการอยู่ในไฟล์เดียว ตัวเลขเป็นตัวเลขจริง นำไปคำนวณต่อได้ทันที

ทุกรายงานระบุ **ช่วงข้อมูล · วันเวลาที่ดึง · ผู้ดึงข้อมูล** ไว้เสมอ

หน้าเดียวกันยังแสดง **รายการที่ต้องดำเนินการ** (โครงการที่ยังไม่บันทึก
หรือใกล้ถึงกำหนดล็อก) และ **ประวัติการแก้ไข** ทั้งหมด

---

## 6. การตั้งค่าระบบ (สำหรับผู้ดูแลระบบ)

### ระยะเวลาล็อกข้อมูลย้อนหลัง
แท็บ **ตั้งค่า** → กำหนดจำนวนวันแยกรายโครงการได้ (แนะนำ 2–3 วัน)
นับจากวันที่ปฏิบัติงาน ไม่ใช่วันที่คีย์ข้อมูล
การเปลี่ยนค่ามีผลกับข้อมูลในอนาคตเท่านั้น ไม่ปลดล็อกข้อมูลที่ล็อกไปแล้ว

### การปิดงวดรายเดือน
แท็บ **แรงงาน-วัน** → ปุ่ม **ปิดงวด** เมื่อปิดแล้วเดือนนั้นแก้ไขไม่ได้อีก
การเปิดงวดคืนต้องระบุเหตุผล และระบบบันทึกไว้ในประวัติ

### การนำเข้าทะเบียนพนักงาน
แท็บ **ตั้งค่า** → **นำเข้าทะเบียนพนักงานจาก Excel**

1. กด **ดาวน์โหลดไฟล์ตัวอย่าง** เพื่อดูชื่อคอลัมน์ที่ระบบเข้าใจ
2. กรอกข้อมูลแล้วเลือกไฟล์
3. กด **ตรวจไฟล์ก่อน** — ระบบจะแสดงว่าแถวไหนไม่ผ่านและเพราะอะไร โดยยังไม่บันทึก
4. เมื่อตรวจแล้วจึงกด **นำเข้าจริง**

รหัสพนักงานที่มีอยู่แล้วจะถูกปรับปรุง ไม่สร้างซ้ำ และระบบไม่ยอมให้รหัสเดียวกัน
อยู่คนละโครงการ

### การกำหนดสิทธิ์
**ตั้งค่า → ผู้ใช้และสังกัดโครงการ** → เลือกผู้ใช้ → แท็บ **สิทธิ์การใช้งาน**
สิทธิ์ **ตรวจสอบและยืนยันข้อมูล** เป็นสวิตช์แยกต่างหาก ใช้แต่งตั้งผู้ตรวจสอบ
โดยไม่ต้องเปลี่ยนบทบาทของผู้ใช้

---

## 7. หัวข้อสำหรับการอบรม

**รอบผู้บันทึกหน้างาน (45 นาที)**
1. เข้าสู่ระบบและเลือกไซต์งาน
2. บันทึกแรงงาน-วันรายคน และบันทึกทั้งทีม
3. สถานะการทำงาน 5 แบบ ใช้เมื่อไร
4. แนบรูปหน้างาน
5. ทดลองปิดสัญญาณแล้วบันทึก เพื่อให้เห็นว่าข้อมูลไม่หาย
6. ยื่นคำขอลาแทนพนักงาน

**รอบผู้ตรวจสอบและผู้บริหาร (30 นาที)**
1. อ่านสถานะ แก้ไขได้ / ใกล้ครบกำหนด / ล็อกแล้ว
2. ตรวจและยืนยันข้อมูลรายวัน
3. อนุมัติการลา
4. อ่านรายงาน 4 มุมมอง และส่งออก PDF / Excel

**รอบผู้ดูแลระบบ (45 นาที)**
1. ตั้งระยะเวลาล็อกรายโครงการ
2. ปิดงวด และการเปิดงวดคืนพร้อมเหตุผล
3. นำเข้าทะเบียนพนักงานจาก Excel และอ่านรายการที่ไม่ผ่าน
4. กำหนดสิทธิ์และแต่งตั้งผู้ตรวจสอบ
5. อ่านประวัติการแก้ไข (Audit Trail)

---

## 8. คำถามที่พบบ่อย

**บันทึกย้อนหลังไม่ได้ ต้องทำอย่างไร**
ถ้าเลยระยะเวลาที่ตั้งไว้ ข้อมูลจะล็อกอัตโนมัติ ให้แจ้งผู้ดูแลระบบ
ซึ่งจะปลดล็อกให้พร้อมระบุเหตุผล และเหตุผลนั้นจะถูกบันทึกไว้ตรวจสอบได้

**กรอกแรงงาน-วันเกิน 1 ไม่ได้**
ถูกต้องแล้ว หนึ่งคนต่อหนึ่งวันมีได้สูงสุด 1 แรงงาน-วัน
ถ้าทำหลายงานในวันเดียว ให้แบ่งสัดส่วน เช่น 0.5 + 0.5

**ลบข้อมูลแล้วหายไปไหน**
ระบบไม่ลบข้อมูลจริง แต่ทำเครื่องหมายยกเลิกไว้ จึงยังตรวจสอบย้อนหลังได้เสมอ

**ตัวเลขในรายงานไม่ตรงกับหน้าจอ**
ไม่ควรเกิดขึ้น ทั้งสองอ่านจากข้อมูลชุดเดียวกัน หากพบกรุณาแจ้งทันที
พร้อมระบุช่วงวันที่และมุมมองรายงานที่ใช้
