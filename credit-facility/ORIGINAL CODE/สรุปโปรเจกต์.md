| รหัส | โครงการ | ข้อมูลจริง |

## 3. ประเภทวงเงินสินเชื่อ (6 ประเภท)

ดึงจากไฟล์วงเงินกู้ของแต่ละโครงการ

| # | ประเภท | กลุ่มแสดงผล |
|---|--------|------------|
| 1 | หนังสือค้ำประกันสัญญา 5% | L/G |

## 4. หลักการคำนวณ ใช้ไป / คงเหลือ

- ระบบยึด **ตัวเลขที่ไฟล์ Excel คำนวณไว้เอง** เป็นยอดตั้งต้น
  `ใช้ไป = วงเงิน − คงเหลือ` (อ่านจากบรรทัด "คงเหลือวงเงินใช้ได้ ( … = … )" หรือยอดดุลบรรทัดสุดท้ายของแต่ละวงเงิน)
- **บรรทัดที่เป็นค่าลบใน Excel = ถูกใช้ไปแล้ว** เช่น BT1 วงเงิน #1 ออกค้ำประกันเต็มจำนวน → ใช้ไป 39,964,779 / **คงเหลือ 0 บาท**
- รายการที่บันทึกผ่านเว็บภายหลังจะปรับยอด: ใส่ค่าบวก = ใช้เพิ่ม, ใส่ค่าลบ = ปลด/คืนวงเงิน (T/L: ตัดชำระเงินต้นลดยอดใช้ไป)
- คำขอที่ได้รับ **อนุมัติ** จะถูกบวกเข้ายอดใช้ไปด้วย
- ถ้าใช้เกินวงเงิน ตารางจะขึ้นสีแดง **⚠ เกินวงเงิน**

## 5. หน้าจอการใช้งาน

**การ์ดสรุป (แดชบอร์ด)** แสดงอยู่ด้านบนของทุกแท็บเสมอ แบ่งเป็น 4 กลุ่ม (คลิกการ์ดเพื่อกรองดูรายการในตารางด้านล่าง):
- **วงเงินสินเชื่อ (วงเงินกู้ระยะยาว)**: T/L · BG (หนังสือค้ำประกัน 3 ประเภทรวมกัน)
- **วงเงินสินเชื่อ (วงเงินหมุนเวียน)**: B/E · P/N
- **ครบกำหนด**: เดือนนี้ · เดือนหน้า
- **สถานะ**: รออนุมัติ (คำขอใหม่ + อยู่ระหว่างเสนอ) · อนุมัติ

**3 แท็บ** (ตารางด้านล่างการ์ดสรุป):
- **วงเงินสินเชื่อ (Facilities)**: ตารางวงเงิน-ใช้ไป-คงเหลือ พร้อมแถบ % การใช้
- **รายการสินเชื่อ (Credit Ledger)**: รายการคำขอและการใช้วงเงินทั้งหมดในตารางเดียว + ปุ่ม **เพิ่มคำขอสินเชื่อ** / **บันทึกการใช้วงเงิน**; เปลี่ยนสถานะ/อนุมัติ/ชำระเงินได้ในรายการ
- **วางแผนสินเชื่อ (T-bar)**: หน้าวางแผนกระแสเงินสด/ครบกำหนดรายเดือน

ตัวกรอง: โครงการ / บริษัท / ประเภทวงเงิน / ระยะเวลา (ครบกำหนด) / สถานะ / ค้นหา

## 6. ฐานข้อมูล (Google Sheet)

สร้างอัตโนมัติชื่อ **"VCB Credit Facility Master"** แท็บหลัก:

| แท็บ | เก็บอะไร |
|------|---------|
| Facilities   | วงเงินแต่ละประเภทต่อโครงการ (วงเงิน, ใช้ไป) |
| Transactions | รายการเคลื่อนไหว/คำขอ L/G / B/E / P/N / T/L (รวมเป็นบัญชีเดียว) |
| Requests     | คำขอสินเชื่อ + สถานะการอนุมัติ |
| Limits       | ปรับวงเงิน/ใช้ไป แบบ override รายโครงการ |
| Audit        | บันทึกประวัติการเพิ่ม/แก้/ลบ พร้อมผู้ทำและเวลา |
| CashPlan ฯลฯ | ข้อมูลหน้าวางแผน T-bar + CategoryCaps/CostCategories |

แก้ไขตัวเลข/ชื่อโครงการได้โดยตรงในชีตนี้ (ยกเว้นยอดตั้งต้นวงเงินที่มาจาก `Seed.js`)
