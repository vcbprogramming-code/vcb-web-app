**บริษัท วิจิตรภัณฑ์ก่อสร้าง จำกัด** · ฉบับผู้พัฒนาเสนอ · 5 กันยายน 2569

## 1. ที่มาของเอกสารฉบับนี้

เอกสารเกณฑ์ตรวจรับฉบับก่อนหน้าอธิบายระบบควบคุมที่มีการยืนยันข้อมูลและการปิดงวด
ซึ่งเป็นคนละสิ่งกับระบบ HR Work Log ที่พนักงานของท่านเปิดใช้อยู่ทุกวัน เมื่อเรา
พัฒนาตามเอกสารนั้น สิ่งที่ส่งมอบจึงไม่ตรงกับที่ท่านคุ้นเคย

เราจึงถอดข้อกำหนดใหม่จาก **ระบบที่ท่านใช้งานจริง** (Google Apps Script) โดยตรง
แล้วระบุแยกไว้ชัดเจนว่าส่วนใดคือของเดิมที่ต้องทำงานได้เหมือนกัน และส่วนใดคือ
สิ่งที่เราเพิ่มให้เกินระบบเดิม ท่านจะได้ตรวจรับจากเอกสารที่ตรงกับของจริง

**หลักที่ยึด** — ระบบเดิมเป็นเครื่องมือกระจายค่าแรงลงหมวดต้นทุนตามสัญญา
ผู้บันทึกกรอกว่า *ทำงานอะไร ให้หมวดต้นทุนใด* แล้วระบบคำนวณแรงงาน-วันให้เอง
ไม่ใช่ให้คนกรอกตัวเลขแรงงาน-วันเอง

## 4. การนับแรงงาน-วัน

**กติกา** — วันที่มีงานลงอย่างน้อยหนึ่งช่อง นับเป็น **1 แรงงาน-วัน** เสมอ
ถ้าวันนั้นลงสองงาน จะแบ่งเป็น **0.5 / 0.5** ต่อรหัส เพื่อกระจายค่าแรงลงหมวด
ต้นทุน ยอดรวมของวันนั้นยังเป็น 1 ไม่มีทางเกิน

| ข้อ | วิธีตรวจ | ผลที่ต้องได้ |
|---|---|---|
| 4.1 | ยังไม่ลงงาน | 0 แรงงาน-วัน |
| 4.2 | ลงงานหลักช่องเดียว | 1.00 แรงงาน-วัน |
| 4.3 | ลงงานที่สองเพิ่ม | ยังเป็น 1.00 — แต่แยกเป็น 0.5 ให้แต่ละรหัส |
| 4.4 | ลบงานที่สองออก | กลับเป็น 1.00 |
| 4.5 | ลบทั้งสองช่อง | 0 — วันนั้นไม่ถูกนับ |
| 4.6 | ไม่มีช่องให้พิมพ์ตัวเลขแรงงาน-วันที่ใดในระบบ | ตรวจทุกหน้าจอ |

## 9. สิ่งที่พัฒนาไว้แล้วแต่ยังปิดอยู่

สิบรายการนี้มาจากเอกสารเกณฑ์ตรวจรับฉบับเดิม เราพัฒนาเสร็จและทดสอบผ่านแล้ว
แต่**ปิดไว้** เพราะระบบที่ท่านใช้จริงไม่มี เปิดกลับได้ทีละรายการเมื่อท่านต้องการ
โดยไม่ต้องพัฒนาใหม่

ยืนยันข้อมูล · ปิดงวดรายเดือน · ช่องกรอกแรงงาน-วันเป็นตัวเลข · แนบไฟล์ในตาราง
รายวัน · รายการแจ้งเตือน · รายงานกำลังคน · ทะเบียนแผนกและตำแหน่ง · นำเข้าพนักงาน
จาก Excel · ลาครึ่งวัน · แนบใบรับรองแพทย์กับใบลา

## 10. เรื่องที่ต้องตกลงกันก่อนเริ่มใช้จริง

1. **ฝึกอบรม / หยุดเนื่องจากสภาพอากาศ** — จะเพิ่มเข้าทะเบียนหรือตัดออกจากเกณฑ์
2. **ผู้อนุมัติการลา** — ระบบเดิมยังไม่ได้กำหนดหัวหน้ารายบุคคล ขอรายชื่อว่าใคร
   อนุมัติให้ใคร มิฉะนั้นคำขอทั้งหมดจะไปที่ผู้ดูแลระบบ
3. **การนำข้อมูลจริงเข้า** — 8 หน่วยงาน พนักงานประมาณ 345 คน และบันทึกย้อนหลัง
   ขอไฟล์หรือสิทธิ์เข้าถึงฐานข้อมูลเดิม พร้อมกำหนดวันหยุดใช้งานเพื่อย้ายข้อมูล
4. **ช่วงเปลี่ยนระบบ** — จะใช้คู่ขนานกับระบบเดิมกี่สัปดาห์ก่อนปิดของเดิม
