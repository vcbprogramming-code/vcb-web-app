# เอกสารข้อกำหนดฟังก์ชัน (Functional Specification) — VCB Connect

เอกสารชุดนี้อธิบาย **ทุกฟังก์ชันของทั้ง 8 โมดูล** ใน VCB Connect โดยละเอียด รวมถึง Logic
การทำงานเบื้องหลัง อ้างอิงจาก **โค้ด React/Express ที่ใช้งานจริงในปัจจุบัน** ภายใต้
`FOR DEPLOYMENT TEAM/` (ไม่ใช่ Apps Script เดิมที่ `ORIGINAL CODE/` ซึ่งยังเป็นระบบ live
ที่พนักงานใช้งานอยู่จริง — ดู [`../../README.md`](../../README.md) และ
[`../../ARCHITECTURE_STANDARD.md`](../../ARCHITECTURE_STANDARD.md) ที่รากของ repo)

แต่ละไฟล์เขียนโดยอ่านซอร์สโค้ดจริงทุกไฟล์ในโมดูลนั้น (หน้าจอ, คอมโพเนนต์, lib, และ
route ฝั่ง API ที่เกี่ยวข้อง) พร้อมระบุชื่อไฟล์/ฟังก์ชันอ้างอิง เพื่อให้นักพัฒนาตามไปดู
โค้ดจริงต่อได้ทันที

## รายการเอกสารทั้ง 8 โมดูล

| โมดูล | ไฟล์ | เนื้อหาโดยสรุป |
|---|---|---|
| Portal | [`portal.md`](portal.md) | หน้าหลัก, sign-in, dashboard, ประกาศ, ปฏิทินวันหยุด, การนำทางไปโมดูลอื่น |
| HR Work Log | [`hr-worklog.md`](hr-worklog.md) | บันทึกการทำงานรายวัน 8 หน่วยงาน, ตัวเลือกกิจกรรม 2 ขั้นตอน, คำขอลา |
| Credit Facility | [`credit-facility.md`](credit-facility.md) | วงเงินสินเชื่อ, การเบิกใช้, คำขอ/อนุมัติ, แผนกระแสเงินสดรายเดือน |
| Meeting Minutes | [`meeting-minutes.md`](meeting-minutes.md) | บันทึกการประชุม, นำเข้าอัตโนมัติจาก Fathom/Transkriptor, ประวัติการแก้ไข |
| SOP | [`sop.md`](sop.md) | ระเบียบปฏิบัติ MANGO ERP, Process Flow, Case Studies, ประวัติเวอร์ชัน |
| System Map | [`system-map.md`](system-map.md) | แผนผังการเชื่อมโยงระบบ (static renderer ไม่มีฐานข้อมูล) |
| Onboarding | [`onboarding.md`](onboarding.md) | ปฐมนิเทศพนักงานใหม่ 90 วัน, checklist, progress tracking |
| E-Memo | [`ememo.md`](ememo.md) | ควบคุมเอกสาร, ออกบันทึกข้อความ, ขั้นตอนอนุมัติ (แอปแยก TypeScript) |

## ข้อควรทราบก่อนอ่าน

- **เอกสารนี้บันทึกสภาพโค้ด ณ วันที่เขียน (2026-09-05)** โค้ดเปลี่ยนแปลงต่อเนื่อง — ถ้า
  พบว่าเนื้อหาใดไม่ตรงกับโค้ดจริงแล้ว ให้เชื่อโค้ดเป็นหลัก ไม่ใช่เอกสารนี้
- ระหว่างเขียนเอกสารชุดนี้ พบว่าไฟล์ `PORT_NOTES.md` ของบางโมดูลมีข้อมูลที่ล้าสมัยไปแล้ว
  (อ้างว่า endpoint บางตัวยังไม่มี ทั้งที่จริงมีอยู่แล้วในโค้ด) — จุดที่พบขัดแย้งกันถูก
  ระบุไว้ในเอกสารของโมดูลนั้นๆ โดยตรง ดูหัวข้อ "ข้อจำกัด" หรือ "ที่มาและข้อจำกัด" ของแต่ละไฟล์
- **E-Memo** เป็นแอป TypeScript แยกต่างหาก อยู่นอกขอบเขตของ `@vcb/shared` และการ sweep
  ข้ามโมดูลใดๆ — พัฒนาโดยทีมภายนอก อย่านำ pattern จากโมดูลนี้ไปใช้กับโมดูลอื่น
- **System Map** ไม่มีฐานข้อมูลหรือ API ใดๆ เป็น static renderer ล้วน
- โมดูลอื่นนอกจากนี้ทั้งหมดคุยกับฐานข้อมูล PostgreSQL ผ่าน Express API ตัวเดียวที่
  `FOR DEPLOYMENT TEAM/api/` เท่านั้น เบราว์เซอร์ไม่ถือ credential ของฐานข้อมูลโดยตรง
