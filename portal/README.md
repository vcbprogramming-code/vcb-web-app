# VCB Connect Portal

The front door to VCB Group's internal web apps — one page of tiles, so staff
have a single link to remember instead of seven.

## What it does

- **App tiles** — one per registered app, each opening in a new tab
- **Announcement banner** — an optional notice across the top, dismissed
  per-device and shown again when the text changes
- **Admin panel** — for editing that announcement
- **EN / TH toggle**, a decorative globe, and a Thai public-holiday calendar

## Notes

The portal holds no business data of its own. It is read-only apart from the
announcement: everything else it shows is a link out to another app.

Because every tile points at another app's address, the portal is the piece that
has to be updated whenever one of those apps moves.
