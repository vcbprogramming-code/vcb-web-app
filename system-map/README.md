# VCB System Operating Map

An interactive map of how VCB Group's systems fit together — which tool owns
which part of the business, and where information passes between them.

Reference material for staff, and for anyone planning changes to how the company
operates.

## What it does

- **One diagram** — lanes for each business function, the systems serving them,
  and the connections between
- **Click through** any part of the map for the detail behind it
- **Written companion** — `COMPANY_OPERATING_MODEL.md` explains in prose what
  the map shows visually

## Notes

The map is reference material, not a record: nothing is entered, saved or
submitted here. Its content is maintained by whoever updates the map, not by
users of the app.
